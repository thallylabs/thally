---
title: "Tooltips"
description: "Add accessible supporting context to a term without leaving the page."
---

Tooltips open on hover or keyboard focus and remain usable on touch devices.
They can include a short headline and an optional destination.

## Example

The <Tooltip tip="A signed token sent with each authenticated request." headline="JSON Web Token" cta="Read API setup" href="/guides/api-reference-setup">JWT</Tooltip> belongs in the `Authorization` header.

```mdx
<Tooltip
  tip="A signed token sent with each authenticated request."
  headline="JSON Web Token"
  cta="Read API setup"
  href="/guides/api-reference-setup"
>
  JWT
</Tooltip>
```

## Props

| Prop | Type | Description |
|---|---|---|
| `tip` | `string` | Required supporting text |
| `headline` | `string` | Optional heading |
| `cta` | `string` | Optional link label |
| `href` | `string` | Safe internal or external destination for the CTA |
