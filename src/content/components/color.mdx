---
title: "Color"
description: "Publish copyable design tokens as compact palettes or reference tables."
---

Use compound color items for complete palettes. Readers can copy each value
directly from the swatch.

## Compact palette

<Color variant="compact">
  <Color.Item name="Accent" light="#7AA600" dark="#B8EC36" />
  <Color.Item name="Warning" value="#F2B84B" />
  <Color.Item name="Danger" value="#F05B61" />
</Color>

```mdx
<Color variant="compact">
  <Color.Item name="Accent" light="#7AA600" dark="#B8EC36" />
  <Color.Item name="Warning" value="#F2B84B" />
</Color>
```

## Reference table

<Color variant="table">
  <Color.Row title="Brand">
    <Color.Item name="Leaf" value="#B8EC36" />
    <Color.Item name="Ink" value="#10140B" />
  </Color.Row>
</Color>

The original `<Color hex="#B8EC36" name="Leaf" />` form remains supported.

## Props

| Component | Props | Description |
|---|---|---|
| `<Color>` | `variant="compact" \| "table"` | Palette layout |
| `<Color.Item>` | `name`, `value`, `light`, `dark` | Named copyable value; use `light` and `dark` together for a theme pair |
| `<Color.Row>` | `title` | Labeled group used in table layouts |
