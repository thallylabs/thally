---
title: "View"
description: "Let readers switch one section between named perspectives."
---

Sibling `<View>` components form one page-level selector. Only the active view
and its headings appear in the rendered table of contents.

## Example

<View title="Node.js" icon="code-simple">
  Install the server SDK:

  ```bash
  npm install @example/server
  ```
</View>

<View title="Python" icon="code-simple">
  Install the Python SDK:

  ```bash
  pip install example-server
  ```
</View>

```mdx
<View title="Node.js" icon="code-simple">
  npm install @example/server
</View>

<View title="Python" icon="code-simple">
  pip install example-server
</View>
```
## Props

| Prop | Type | Description |
|---|---|---|
| `title` | `string` | Required selector label |
| `icon` | `string` | Optional selector icon |
| `iconType` | `string` | Requested icon style |

## Embed an external demo

The iframe component that earlier Thally versions called `View` is available
as `<Embed>` and `<LegacyView>`.

```mdx
<Embed src="https://example.com/demo" height={500} title="Interactive demo" />
```
