---
title: "Request and response examples"
description: "Keep runnable API examples in the contextual side panel."
---

Place `<RequestExample>` and `<ResponseExample>` inside `<Panel>`. They occupy
the page’s right column on desktop and return to the authored reading position
on smaller screens.

<Panel>
  <RequestExample dropdown>
  ```bash cURL
  curl -X POST https://api.example.com/pets \
    -H "Authorization: Bearer $API_KEY" \
    -d '{"name":"Mori","species":"dog"}'
  ```
  </RequestExample>

  <ResponseExample dropdown>
  ```json 201 Created
  { "id": "pet_42c7", "name": "Mori", "status": "available" }
  ```
  </ResponseExample>
</Panel>

```mdx
<Panel>
  <RequestExample dropdown>
  \`\`\`bash cURL
  curl https://api.example.com/pets
  \`\`\`
  </RequestExample>

  <ResponseExample dropdown>
  \`\`\`json 200
  { "data": [] }
  \`\`\`
  </ResponseExample>
</Panel>
```

Use `InlineRequestExample` and `InlineResponseExample` when an example should
remain in the main article at every viewport size.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `dropdown` | `boolean` | `false` | Allows readers to collapse the example |
