---
title: "Panel"
description: "Place supporting content in the page’s contextual right column."
---

`<Panel>` replaces the desktop **On this page** column with authored supporting
content. On smaller screens, the panel stays at its authored location in the
reading flow.

<Panel>
  <RequestExample>
  ```bash cURL
  curl https://api.example.com/v1/projects \
    -H "Authorization: Bearer $API_KEY"
  ```
  </RequestExample>

  <ResponseExample>
  ```json 200
  { "data": [{ "id": "project_7fd2" }] }
  ```
  </ResponseExample>
</Panel>

```mdx
<Panel>
  <RequestExample>
  \`\`\`bash cURL
  curl https://api.example.com/v1/projects
  \`\`\`
  </RequestExample>

  <ResponseExample>
  \`\`\`json 200
  { "data": [] }
  \`\`\`
  </ResponseExample>
</Panel>
```

## Legacy inline panel

Use `<InlinePanel title="Configuration">` for the bordered content container
that earlier Thally releases called `<Panel>`.

<InlinePanel title="Configuration">
  Set `THALLY_API_KEY` before running the synchronization command.
</InlinePanel>
