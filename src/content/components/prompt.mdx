---
title: "Prompt"
description: "Give readers a ready-to-copy prompt for an AI coding agent."
---

`<Prompt>` presents a task description, exact clipboard payload, and optional
actions for copying or opening the prompt in Cursor.

## Example

<Prompt
  description="Ask an agent to add authenticated API examples"
  actions={["copy", "cursor"]}
  icon="sparkles"
>
Review the authentication guide and add one valid cURL example for every
supported authentication method. Preserve existing prose and verify each
header name against the OpenAPI specification.
</Prompt>

```mdx
<Prompt
  description="Ask an agent to add authenticated API examples"
  actions={["copy", "cursor"]}
  icon="sparkles"
>
Review the authentication guide and add one valid cURL example for every
supported authentication method.
</Prompt>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `description` | `string` | — | Required visible summary |
| `actions` | `Array<"copy" \| "cursor">` | `["copy"]` | Available prompt actions |
| `icon` | `string` | `"sparkles"` | Leading icon |
| `iconType` | `string` | `"outline"` | Requested icon style |

## Legacy terminal

Earlier Thally releases used `Prompt` for transcripts. Use the explicit
`Terminal`, `TerminalInput`, and `TerminalOutput` aliases for that presentation.

<Terminal>
  <TerminalInput>npm run build</TerminalInput>
  <TerminalOutput>Build completed in 2.4 seconds.</TerminalOutput>
</Terminal>
