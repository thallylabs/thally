---
title: "Accordions"
description: "Reveal supporting details without interrupting the main reading flow."
---

Use `<Accordion>` for progressive disclosure. Opening an accordion with an
`id` updates the URL hash, so readers can link directly to that section.

## Single accordion

<Accordion
  title="What is an API key?"
  description="Authentication and safe storage"
  icon="key-round"
  id="what-is-an-api-key"
>
  An API key authenticates requests from your application. Store it in a
  server-side secret manager and never expose it in browser code.
</Accordion>

## Accordion group

`<AccordionGroup>` joins related items into one visually continuous control
and preserves Radix keyboard navigation between triggers.

<AccordionGroup>
  <Accordion title="Create a key" icon="plus">
    Open **Settings → API keys** and choose **Create key**.
  </Accordion>
  <Accordion title="Rotate a key" icon="refresh-cw">
    Create the replacement first, update your service, then revoke the old key.
  </Accordion>
  <Accordion title="Revoke a key" icon="trash-2">
    Revocation is immediate and cannot be undone.
  </Accordion>
</AccordionGroup>

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` | `string` | — | Required trigger label |
| `description` | `string` | — | Supporting text below the title |
| `defaultOpen` | `boolean` | `false` | Opens the item on first render |
| `id` | `string` | Derived from title | Stable anchor used for deep links |
| `icon` | `string` | — | Icon name displayed before the title |
| `iconType` | `string` | `"outline"` | Requested icon style |
