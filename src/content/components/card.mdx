---
title: "Cards"
description: "Create scannable navigation, feature, and intent-aware content cards."
---

Use `<Card>` on its own or place related cards in a responsive `<CardGroup>`.

## Example

<CardGroup cols={2}>
  <Card title="Quickstart" icon="party-horn" href="/quickstart" cta="Start building">
    Get a documentation site running locally in a few minutes.
  </Card>
  <Card title="API reference" icon="code-simple" href="/api" type="info">
    Explore generated endpoints, schemas, and request examples.
  </Card>
</CardGroup>

```mdx
<Card
  title="Quickstart"
  icon="party-horn"
  href="/quickstart"
  cta="Start building"
>
  Get a documentation site running locally in a few minutes.
</Card>
```

## Horizontal card

<Card title="Writing guide" icon="refresh-cw" href="/guides/writing-content" horizontal arrow>

</Card>

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` | `string` | — | Card heading |
| `href` | `string` | — | Internal or external destination |
| `icon` | `string` | — | [Icon name](/components/icons) |
| `color` | `string` | Theme accent | Icon color |
| `img` | `string` | — | Image displayed above or beside the content |
| `horizontal` | `boolean` | `false` | Uses a horizontal layout |
| `cta` | `string` | — | Explicit action label |
| `arrow` | `boolean` | Inferred from `href` | Shows the directional arrow |
| `type` | `info \| warning \| note \| tip \| check \| danger` | — | Intent-aware surface treatment |

`<CardGroup cols={1|2|3|4}>` controls the responsive grid.
